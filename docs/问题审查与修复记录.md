## 3. 修复明细

### 3.1 压缩摘要块上限(高)

文件:`src/thesis_agent/memory/conversation.py`

- `__init__` 新增 `max_compacted: int = 3` 参数;
- `apply_compaction`:压缩块超过上限时丢弃最旧块(信息价值最低);
- `build`:防御性截取最近 `max_compacted` 块,兼容历史 checkpoint 中已超限的数据;
- `total_tokens`:把压缩块也计入 token 估算(压缩块同样占用上下文窗口)。

### 3.2 MemoryStore 并发安全(中)

文件:`src/thesis_agent/memory/store.py`

- 连接后执行 `PRAGMA journal_mode=WAL`(读写并发)与 `PRAGMA busy_timeout=5000`(争锁时等待而非直接报错)。

### 3.3 反馈采纳追踪接入 + 稳定 key(中)

文件:`src/thesis_agent/memory/experience.py`、`src/thesis_agent/graph/nodes/review.py`

- 新增 `_issue_key(chapter_id, issue)`:用 `hashlib.md5` 生成稳定 key,替代内置 `hash()`(跨进程随机化问题);
- `review_router_node` 每次评审后调用 `record_feedback_adoption`:`approved` 记为已采纳,`in_revision` 记为未采纳;
- `feedback_summary` 原有逻辑不变,现在有真实数据可汇总。

### 3.4 文档修正(低)

文件:`docs/技术文档.md`

- §7.1 目录注释:`search/paper_search.py` 由"未接入编排"改为"已接入 research_node 补充检索";
- 顶部项目路径更新为当前机器路径;
- §11 变更记录补充本次修复条目。

## 4. 改动文件清单

# 第二次审查:引用治理与运行可视化(2026-08-25)

> 日期:2026-08-25
> 范围:引用一致性闭环失效(产出物验证发现)+ 运行过程不可见,共 6 项增强。

## 1. 审查结论

对 `data/output/consistency_check.txt` / `final_paper.md` / `references.bib` 的真实产出核验发现:**"防幻觉引用"核心能力失效**——正文残留大量未改写的 `[Author et al., YYYY]` 引用、引用库混入与 DLA 主题无关的论文、LLM 一致性检查因引用被截断产生系统性误报。另据运行体验,长周期撰写过程完全不可见。本次完成 6 项修复/增强。

## 2. 问题清单与解决情况

| # | 问题 | 严重度 | 状态 | 说明 |
|---|------|--------|------|------|
| 1 | `rewrite_author_year_citations` 未匹配警告被 `_warnings` 丢弃,改写失败静默 | 高 | 已修复 | editor 把警告上报 `consistency_problems` |
| 2 | Drafter 可凭空捏造素材库之外的引用(如 `Li et al., 2022`) | 高 | 已修复 | 引用白名单注入提示词,只允许引用素材库论文 |
| 3 | Critic 评审不核查引用来源 | 中 | 已修复 | 评审携带章节素材,`_CRITIC_SYSTEM` 逐条核对白名单 |
| 4 | 引用库混入离题论文(暗能量/区块链等);`build_citations` 只过滤损坏条目 | 高 | 已修复 | `_filter_topic_relevant` LLM 主题过滤 |
| 5 | Finalize LLM 检查喂截断引用列表,`sun2025...` 等在库却报无匹配 | 高 | 已修复 | LLM 检查改为只查结构,引用校验由规则全文核对 |
| 6 | `Peña`/`peña` 音调差异导致 key 匹配失败;key 含非 ASCII 字符 | 中 | 已修复 | `_normalize_surname` NFKD 归一化统一四处使用 |
| 7 | 撰写/评审过程不可见,失败难排查 | 中 | 已修复 | 新增 FastAPI 运行看板(`serve`,3 秒轮询展示任务板/记忆库) |

## 3. 修复明细

### 3.1 引用治理闭环(高)

文件:`src/thesis_agent/citations/bibtex.py`、`src/thesis_agent/graph/nodes/draft.py`、`review.py`、`editor.py`、`finalize.py`

- `bibtex.py`:新增 `_normalize_surname`(NFKD 去音调+小写),`make_citation_key`/`_first_author_surname`/改写/校验四处统一使用;
- `draft.py`:新增 `_format_whitelist` 从素材生成可引用白名单,注入 Drafter 提示词(规则 3 禁引白名单外来源);
- `review.py`:`review_dispatch_edge` 把章节素材随 Send 传给评审节点,`_CRITIC_SYSTEM` 要求逐条核对草稿引用;
- `editor.py`:rewrite 警告不再丢弃(上报 `editor-N` 问题);新增 `_filter_topic_relevant` 用 cheap 档 LLM 剔除明显离题论文(JSON 异常宁多勿删);
- `finalize.py`:`_FINAL_CHECK_SYSTEM` 改为结构检查,不再喂截断引用判引用匹配。

### 3.2 运行可视化(中)

文件:`src/thesis_agent/dashboard.py`(新增)、`src/thesis_agent/cli.py`、`pyproject.toml`

- 新增 `dashboard.py`:FastAPI 应用,`GET /` 看板页 + `GET /api/tasks`(任务板按 run_id 分组/状态统计)+ `GET /api/memory`(长期记忆按 namespace 折叠展示);

# 第三次审查:索引重建与聊天命令(2026-08-25)

> 日期:2026-08-25
> 范围:`ingest --rebuild` 崩溃、Web 聊天 `/search`/`/rag` 命令形同虚设、默认端口占用,共 3 项处理。

## 1. 审查结论

用户按使用说明执行 `thesis-agent ingest --rebuild` 时崩溃;Web 聊天界面的 `/search`/`/rag` 命令此前仅做前端前缀填充,后端仍把消息交给 LLM 自主决策,不保证触发工具;另本机 8000 端口被其他程序占用。3 项均已处理。

## 2. 问题清单与解决情况

| # | 问题 | 严重度 | 状态 | 说明 |
|---|------|--------|------|------|
| 1 | `ingest --rebuild` 报 `AttributeError: 'FaissShards' object has no attribute 'dim'` | 高 | 已修复 | `rebuild_shard` 空分片分支引用未初始化的 `self.dim`;新增维度推断,全库无向量时跳过空分片 |
| 2 | Web 聊天 `/search`、`/rag` 命令不保证触发工具(消息直接交给 LLM 自主决策) | 中 | 已修复 | 命令正则直调:不经 LLM、不耗 token、不进对话记忆 |
| 3 | `serve` 默认端口 8000 被本机其他程序占用 | 低 | 已修复 | 默认端口改 9000(CLI/vite 代理/文档同步) |

## 3. 修复明细

### 3.1 rebuild 空分片维度推断(高)

文件:`src/thesis_agent/rag/index.py`

- `MetadataDB` 新增 `any_chunk_vector()`:取任意一条分块向量(推断维度用);
- `FaissShards` 新增 `_infer_dim()`:优先从元数据向量,其次读已有分片维度,全库无向量返回 0;
- `rebuild_shard` 空分片分支:推断到维度则写空索引,否则跳过(检索会忽略缺失分片)。

### 3.2 聊天命令直调(中)

文件:`src/thesis_agent/chat_api.py`

- 新增 `_COMMAND_RE`(`^/?(search|rag)\s+(.+)$`)与 `_run_command`:`/search`、`/rag`(含不带斜杠)强制调用 `web_search` / `retrieve_local` 并推送 `tool_call`/`tool_result` 事件;
- `run()` 中命令优先处理,不经过 LLM、不写入对话记忆;结构化结果可直接收藏。

### 3.3 默认端口 9000(低)

文件:`src/thesis_agent/cli.py`、`frontend/vite.config.js`

- `serve --port` 默认 8000 → 9000;vite dev 代理同步;文档同步更新。

|------|------|

| `src/thesis_agent/chat_api.py` | `/search`、`/rag` 命令直调 |

## 5. 遗留风险与下一步

- 空分片在"全库无任何向量"时跳过写索引(首次 `--rebuild` 于空库上),检索自动忽略缺失分片,入库后正常重建;
